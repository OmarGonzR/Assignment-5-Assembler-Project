# Assignment-5-Assembler-Project

Create Assembler.java, MachineCodeFile.java, Disassembler.java and fizzbuzz.asm. Have them all in the same folder and open a terminal in that folder. Once you compile Assembler.java, MachineCodeFile.java and Disassembler.java the assembler class will read fizzbuzz.asm and creates fizzbuzz.mhc-ascii and fizzbuzz.mhc-bin. The disassembler class will reconstruct machine code into MIPS code and make sure that after reassembling it preserves all instruction and data bytes.
